# LinguaLearn: Language Learning App

A language learning app built for the CodeAlpha App Development internship (Task 4).

## Features

- 21 languages (Spanish, French, German, Hindi, Punjabi, Tamil, Japanese and more)
- Flashcards for vocabulary and phrases, with a "Show meaning" button
- Search any English word or phrase and see its translation
- Save searched words to a personal "My words" list
- Listen button for pronunciation (uses the browser's built-in voices)
- Quizzes in any language, with scores
- Progress tracking: words learned, best scores, quizzes completed
- Data saved in the browser (localStorage)

## Technologies

- HTML, CSS and JavaScript
- MyMemory Translation API for translations
- Web Speech API for pronunciation

## How to run

1. Download or clone this repo.
2. Open `index.html` in a browser (internet needed for new translations).

## Live demo

https://floralsk7-blip.github.io/CodeAlpha_LanguageLearningApp/

## Notes

- The free translation API allows about 5,000 characters per day per user.
- Pronunciation needs a text-to-speech voice for the language to be installed on the device.
- Machine translations can sometimes be inaccurate.
